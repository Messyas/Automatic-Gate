# Pipeline de Detecção e Segmentação de Placas de Veículos

Este módulo faz parte de um sistema de controle de portaria que utiliza visão computacional e deep learning para detectar e segmentar placas de veículos. Foi desenvolvido para o curso de Visão Computacional, no Projeto Aranouá.

---

## 📋 Pré-requisitos

- **Conda** (Anaconda ou Miniconda)
- **Python 3.9**
- **git** (opcional, para clonar o repositório)

---

## 🚀 Configuração do Ambiente

Abra um terminal e execute os comandos abaixo:

```bash
# 1. Crie o ambiente conda com Python 3.9
env_name=nome-repo
conda create -n $nome-repo python=3.9

# 2. Ative o ambiente
conda activate $nome-repo

# 3. Instale as dependências
git clone <URL_DO_REPOSITORIO>
cd <NOME_DO_REPOSITORIO>
pip install -r requirements.txt
```

> **Nota:** Se você não for usar git, faça o download do código e navegue até a pasta do projeto antes de instalar as dependências.
